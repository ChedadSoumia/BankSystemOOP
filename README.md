# Bank system :

A Console-Based Banking System developed in C++ using Object-Oriented Programming (OOP) principles.

The system provides a complete simulation of real-world banking operations with a focus on clean architecture, maintainability, and user experience.

### Key Features:

* 🔐 Secure Login System with masked password input and tracking of user login/logout history
* 🌍 Multi-language support (English & French)
* 👥 Client Management: Add, Delete, Update, Search, Deposit, and Withdraw
* 👤 User Management: Add, Delete, Update, and Search system users
* 💸 Transfer System: Perform and track money transfers between clients
* 💱 Currency Management: Handle and manage different currencies

### Technical Highlights:

* Built with pure C++ (Console Application)
* Strong implementation of OOP concepts (Encapsulation, Inheritance, Abstraction)
* Modular and scalable code structure
* File handling for data persistence

This project demonstrates practical problem-solving skills and simulates a real banking environment using structured and maintainable code.
